# SWECOM 13 Skill Areas Reference

## 5 Life Cycle Skill Areas:

1. **Software Requirements**
   - Requirements Elicitation
   - Requirements Analysis
   - Requirements Specification
   - Requirements Verification and Validation
   - Requirements Process and Product Management

2. **Software Design**
   - Design Fundamentals
   - Design Strategies and Methods
   - Architectural Design
   - Design Quality Analysis and Evaluation

3. **Software Construction**
   - Construction Planning
   - Managing Software Construction
   - Detailed Design and Coding
   - Debugging and Testing
   - Integrating and Collaborating

4. **Software Testing**
   - Test Planning
   - Testing Infrastructure
   - Testing Techniques
   - Testing Measurement and Defect Tracking

5. **Software Sustainment**
   - Software Transition
   - Software Support
   - Software Maintenance

## 8 Crosscutting Skill Areas:

6. **Software Process and Life Cycle**
   - Life Cycle Implementation
   - Process Definition and Tailoring
   - Process Implementation and Management
   - Process Assessment and Improvement

7. **Software Systems Engineering**
   - System Development Life Cycle Modeling
   - Concept Definition
   - System Requirements Engineering
   - System Design
   - Requirements Allocation
   - Component Engineering
   - System Integration and Verification
   - System Validation and Deployment
   - System Sustainment Planning

8. **Software Quality**
   - Software Quality Management
   - Reviews (walkthrough, inspection)
   - Audits
   - Statistical Control

9. **Software Security**
   - Security Requirements
   - Security Design
   - Security Construction
   - Security Testing
   - Security Process
   - Security Quality

10. **Software Safety**
    - Safety Requirements
    - Safety Design
    - Safety Construction
    - Safety Testing
    - Safety Process
    - Safety Quality

11. **Software Configuration Management**
    - Plan SCM
    - Conduct SCM
    - Manage Software Releases

12. **Software Measurement**
    - Plan Measurement Process
    - Perform Measurement Process

13. **Human-Computer Interaction**
    - Requirements
    - Interaction Style Design
    - Visual Design
    - Usability Testing and Evaluation
    - Accessibility
