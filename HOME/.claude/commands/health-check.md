Run a comprehensive project health check:

1. **Code Quality** (Code Quality Engineer):
     - Review 3-5 main modules for complexity, duplication, tech debt
     - Identify top 3 refactoring priorities

2. **Metrics Baseline** (Metrics Analyst):
     - Establish code coverage, complexity, duplication baselines
     - Set targets for improvement

3. **Accessibility** (Accessibility Specialist - if web app):
     - Audit main user flows for WCAG compliance
     - Identify critical accessibility issues

4. **Documentation** (Tech Writer):
     - Check API docs are current
     - Verify README is accurate
     - Identify missing documentation

5. **Security** (Security Engineer):
     - Review database RLS policies
     - Check authentication/authorization
     - Identify security gaps

Produce a prioritized action plan with effort estimates.
