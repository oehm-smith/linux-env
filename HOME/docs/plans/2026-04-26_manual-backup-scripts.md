# Manual Backup Scripts

## Overview

A Python-based manual backup system with three components:

1. **`brookelib/nas.py`** — Mount/unmount SMB NAS shares using macOS Keychain credentials
2. **`brookelib/backup.py`** — Rsync wrapper with smart exclude/include lists
3. **`~/bin/backup-install`** — Scaffolding script that generates a project-local `backup.py`

## Component Design

### 1. brookelib/nas.py — NAS Mount/Unmount

**Responsibilities:** Mount and unmount SMB shares on macOS, retrieving credentials from Keychain.

**Public API:**

```python
def get_password(server: str, account: str) -> str:
    """Retrieve password from macOS Keychain for a server/account pair."""

def is_mounted(mount_point: str) -> bool:
    """Check whether a path is an active mount point."""

def mount(mount_point: str = "/Volumes/backup",
          server: str = "home-nas.local",
          share: str = "backup",
          user: str = "brooke") -> None:
    """Mount an SMB share. Retrieves password from Keychain.

    No-op if already mounted.
    """

def unmount(mount_point: str = "/Volumes/backup") -> None:
    """Unmount a mount point. No-op if not mounted."""
```

**Implementation notes:**
- `get_password` calls `security find-internet-password -s <server> -a <account> -w`
- `mount` calls `mount_smbfs //user:password@server/share mount_point`
- `unmount` calls `umount mount_point`
- Create mount_point directory if it doesn't exist
- Password must be URL-encoded in the mount command (special characters)

### 2. brookelib/backup.py — Rsync Wrapper

**Responsibilities:** Run rsync in archive mode with configurable exclude/include lists. No deletes at either end.

**Public API:**

```python
DEFAULT_EXCLUDES: list[str]  # known cache/lib/temp dirs
# e.g. node_modules, .venv, __pycache__, .git, .tox, .mypy_cache,
#      .pytest_cache, .eggs, *.egg-info, .DS_Store, .idea, .vscode,
#      *.pyc, .next, .nuxt, dist, build, .cache, .parcel-cache,
#      .turbo, .svelte-kit, .angular, bower_components, vendor (PHP/Ruby)

def run_backup(source: str, dest: str,
               excludes: list[str] | None = None,
               includes: list[str] | None = None,
               dry_run: bool = False) -> None:
    """Rsync source into dest in archive mode, no deletes.

    Args:
        source: Source directory path (trailing slash added automatically).
        dest: Destination directory path.
        excludes: Dirs/patterns to exclude. Defaults to DEFAULT_EXCLUDES.
        includes: Items to re-include even if in excludes list.
                  These are removed from the effective exclude list.
        dry_run: If True, run rsync with --dry-run and print what would change.
    """
```

**Rsync flags:** `-av --progress` (archive, verbose, progress). No `--delete`.

**Exclude/include logic:** The effective exclude list is `excludes - includes`. This means the user edits the includes list to override specific excludes without touching the exclude list itself.

### 3. ~/bin/backup-install — Scaffolding Script

**What it does:** Run from a project directory. Prompts for config values, scans for excludable dirs, writes a `backup.py` script into the current directory.

**Interactive prompts:**

| Prompt | Default | Notes |
|--------|---------|-------|
| Backup name | Current directory name | Used in log messages |
| NAS user | `brooke` | Hit enter to accept |
| Destination path | `/Volumes/backup` | User MUST change this to a subdirectory or different path entirely. Script rejects bare `/Volumes/backup`. |
| NAS server | `home-nas.local` | |
| NAS share | `backup` | |

**Directory scanning:**
- Scans current dir for known excludable directories (node_modules, .venv, tmp, .git, etc.)
- Prints what was found and which will be excluded by default
- For `tmp` dirs specifically, notes they exist and asks whether to exclude

**Generated `backup.py` template:**

```python
#!/usr/bin/env python3
"""Backup script for <name>. Generated by backup-install."""

from brookelib.nas import mount, unmount, is_mounted
from brookelib.backup import run_backup, DEFAULT_EXCLUDES
import argparse
import sys

# --- Configuration (edit these) ---
SOURCE = "<absolute path to this directory>"
DEST = "<destination path>"
NAS_SERVER = "home-nas.local"
NAS_SHARE = "backup"
NAS_USER = "brooke"
MOUNT_POINT = "/Volumes/backup"

# Directories/patterns to exclude (from DEFAULT_EXCLUDES + detected dirs).
# Do NOT edit this list to add dirs back — use INCLUDES below instead.
EXCLUDES = [
    # ... populated from DEFAULT_EXCLUDES + any detected dirs
]

# Directories to include even though they appear in EXCLUDES above.
# Move items here from EXCLUDES to back them up.
INCLUDES = [
    # e.g. "node_modules",  # uncomment to back up node_modules
]

def main():
    parser = argparse.ArgumentParser(description="Backup <name>")
    parser.add_argument("--dry-run", action="store_true",
                        help="Show what would be synced without doing it")
    parser.add_argument("--no-unmount", action="store_true",
                        help="Leave NAS mounted after backup")
    args = parser.parse_args()

    needs_mount = not is_mounted(MOUNT_POINT)
    if needs_mount:
        mount(MOUNT_POINT, NAS_SERVER, NAS_SHARE, NAS_USER)

    try:
        run_backup(SOURCE, DEST, excludes=EXCLUDES,
                   includes=INCLUDES, dry_run=args.dry_run)
    finally:
        if needs_mount and not args.no_unmount:
            unmount(MOUNT_POINT)

if __name__ == "__main__":
    main()
```

**Key behaviours:**
- Script is `chmod +x` after generation
- `--no-unmount` leaves NAS mounted after backup
- `--dry-run` shows what rsync would do
- Only unmounts if this script was the one that mounted (if already mounted, leave it alone)
- Destination validation: rejects bare `/Volumes/backup` — user must specify a subdirectory
